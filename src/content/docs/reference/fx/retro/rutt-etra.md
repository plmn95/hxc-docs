---
title: "Rutt-Etra"
description: "Displaces raster lines according to image brightness."
---

Displaces raster lines according to image brightness. Brighter areas bend
the lines farther from their original positions. Gaps between lines are
transparent.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| `Density` | Trough | 8 to 256 | Line density. |
| `Displacement` | Trough | 0 to 1 | |
| `Angle` | Wheel | -180 to 180 degrees | Tilts the raster scan lines. |
| `Line Width` | Trough | 0.5 to 8 px | |
| `Brightness` | Trough | 0 to 4 | |
