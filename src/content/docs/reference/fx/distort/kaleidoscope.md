Mirrors the image into a wedge and repeats it around the center.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| `Segments` | Trough | 2 to 16 | Number of repeated wedges. |
| `Rotation` | Wheel | -180 to 180 degrees | |
| `Mirror X` / `Mirror Y` | Rockers | | Mirrors the source horizontally or vertically. Cannot be modulated. |
