## Save your pattern

Choose `File > Save As...` or press `Ctrl+Shift+S` (`Cmd+Shift+S` on
macOS). Save the animated patch as `First kaleidoscope.hxc`.

## Record a clip

Open `View > Settings` and select `Recording`. Choose `H.264` and `30`
frames per second for this first clip. Check `Output Folder` before
recording so you know where the file will go.

[![Recording settings showing H.264, 30 frames per second, and the Output Folder field.](../../images/getting-started/recording-settings.png)](../../images/getting-started/recording-settings.png)

Click `REC` in the main toolbar, let the pattern run for ten seconds,
then click `REC` again to stop.
The shortcut is `Ctrl+Alt+R` on Windows/Linux or `Cmd+Option+R` on macOS.

![The main toolbar's REC control and the camera control beside it.](../../images/getting-started/recording-controls.png)

Wait for the message showing the saved path. If `Saving...` appears,
the file is still being written. Open that MP4 in a video player and check the animation
before recording a longer performance.

If recording fails or skips frames, see
[Troubleshooting](../../troubleshooting/).

For PNG snapshots and live output to other applications, see
[Output and Recording](../../concepts/output-and-recording/).
