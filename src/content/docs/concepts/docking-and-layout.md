---
title: "Docking and Layout"
description: "Arrange Hex Composer windows by docking, resizing, tabbing, and using the View menu."
---

Arrange windows around the controls you use together. Drag a window's tab
to dock it beside another window or combine them as tabs, then drag the
divider to resize the dock.

Use `View` to reopen a hidden window. `Module` and `Modulation` share a dock
in the default layout, as do `Chain` and `Patches`, so a window can be open
but behind another tab.

`View > Layouts > Save Layout As...` saves a named layout. Saved layouts
appear in the same menu. `Restore Default Layout` restores `Output` in the
center, `Module` and `Modulation` as tabs on the right, and `Chain` and
`Patches` as tabs across the bottom.

Related: [Reading the Panel](../reading-the-panel/).
